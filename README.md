# ダンジョン・ナンパ・クロニクル

2Dローグライク RPG — ターミナルで遊べる不思議のダンジョン系ゲーム

## 遊び方

```bash
python main.py
```

### 操作方法

| キー | アクション |
|------|-----------|
| `h` / `←` | 左に移動 |
| `j` / `↓` | 下に移動 |
| `k` / `↑` | 上に移動 |
| `l` / `→` | 右に移動 |
| `y` | 左上に移動 |
| `u` | 右上に移動 |
| `b` | 左下に移動 |
| `n` | 右下に移動 |
| `.` | 待機 |
| `g` | アイテムを拾う |
| `i` | インベントリを開く |
| `s` | 合成袋を使う |
| `>` | 階段を降りる |
| `q` | ゲーム終了 |

## システム

- **LP (Lust Point)**: HP。0でゲームオーバー
- **MP (Mote Point)**: 満腹度。歩くたびに減少
- **トーク力**: ナンパ（攻撃）の威力
- **メンタル耐性**: 受けるダメージを軽減
- **チャラさレベル**: 経験値で上昇

## 要件

- Python 3.8+
- ターミナル (curses対応)
