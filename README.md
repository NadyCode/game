# ダンジョン・ナンパ・クロニクル

2Dドット絵風ローグライクRPG — ブラウザで遊べる不思議のダンジョン系ゲーム

## 遊び方

`index.html` をブラウザで開くだけ！

### 操作方法

| キー | アクション |
|------|-----------|
| `W/A/S/D` or 矢印キー | 移動（敵に向かうとナンパ攻撃） |
| テンキー `1-9` | 8方向移動 |
| `.` / `5` | 待機 |
| `G` | アイテムを拾う |
| `I` | インベントリを開く |
| `S`（探索中） | 合成 |
| `>` | 階段を降りる |

### インベントリ内

| キー | アクション |
|------|-----------|
| `↑/↓` | アイテム選択 |
| `Enter` | 使う |
| `E` | 装備する |
| `D` | 地面に置く |
| `I` / `Q` | 閉じる |

## システム

- **LP (Lust Point)**: HP。0でゲームオーバー
- **MP (Mote Point)**: 満腹度。歩くたびに減少
- **トーク力**: ナンパ（攻撃）の威力
- **メンタル耐性**: 受けるダメージを軽減
- **チャラさレベル**: 経験値で上昇

## 技術スタック

- HTML5 Canvas
- Vanilla JavaScript (依存ライブラリなし)
- ブラウザで直接開くだけで動作
